# web

Part of the **Acme** demo organisation behind [demo.shipglance.com](https://demo.shipglance.com):
five repositories where coding agents keep shipping, so the live deployment
board always has something real to show. The customer-facing web app, deployed to dev then prod.

Every commit, workflow run and deploy here is real. The commits are made by
a storyline driver on a schedule; the tests, environments and deploys are
ordinary GitHub Actions. Nothing is mocked. Deployed versions are live at
`https://acme.shipglance.com/web/<env>`.

Built by [Last Ridge](https://lastridge.com) for [ShipGlance](https://shipglance.com).
